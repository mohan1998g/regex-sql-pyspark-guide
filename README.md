# Regex Reference Package

A GitHub-ready package containing:

- **docs/Regex_Complete_Notes.md** — Detailed notes with examples and a conceptual diagram.
- **docs/Regex_Cheat_Sheet.md** — One-page quick reference.
- **docs/Regex_Tutorial_SQL_PySpark.md** — Practical tutorial focused on SQL & PySpark.

## Getting Started
Clone the repository (or unzip) and open the files in `docs/`.

```bash
# Example: open locally
open docs/Regex_Complete_Notes.md
```

## Contents
- `docs/Regex_Complete_Notes.md`
  - Core syntax: metacharacters, classes, quantifiers, anchors
  - Groups, lookarounds, flags
  - Common patterns and performance tips
- `docs/Regex_Cheat_Sheet.md`
  - Essential syntax in one page
  - Handy snippets (email, IPv4, dates, hashtags, numbers)
- `docs/Regex_Tutorial_SQL_PySpark.md`
  - SQL dialect examples (PostgreSQL, MySQL 8+, BigQuery, Snowflake, Spark SQL)
  - PySpark DataFrame APIs: `regexp_extract`, `regexp_replace`, `split`, `rlike`
  - Exercises and hints
